Study Designs
=============

sctrial matches the analysis to the design of the study. Each clip below illustrates one design or
one property of the analysis. The clips are schematic: a sphere stands for one participant, a small
dot for one cell, and no clip shows data. Select an item to play it.

.. raw:: html

   <link rel="stylesheet" href="_static/clips/web/player.css">
   <div id="sctrial-features"></div>
   <script src="_static/clips/web/studio.js"></script>
   <script src="_static/clips/web/player.js"></script>
   <script>
     window.Studio.mount(document.getElementById("sctrial-features"))
       .catch((error) => console.error("sctrial features:", error));
   </script>

The corresponding functions are described in :doc:`concepts` and in the :doc:`api/index`.
